# 💼Salary Dashboard

An interactive Power BI dashboard that showcases salary trends and job market statistics in the data science field. This dashboard offers insights into compensation based on job roles, employment type, and geographic location — helping job seekers and hiring managers make informed decisions.

---

## 🖼️ Project Snapshot

![Salary Dashboard]((https://github.com/Sumit-Data-Analyst/Salary-Insights-Dashboard/blob/main/ex.PNG)

---

## 🎯 Objective

To visualize and explore data science salary insights using interactive filters such as:
- Job Title
- Country
- Employment Type

---

## 📌 Key Features

✅ Median salary based on selected job title  
✅ Comparison of salary ranges across various data science roles  
✅ Job distribution by employment type (Full-time, Part-time, Contractor, etc.)  
✅ Top job platforms for job seekers  
✅ Country-based insights with map visualizations  
✅ Total job count displayed in real-time  

---

## 🔍 Insights from the Sample Dashboard

- **Selected Job Title**: Data Analyst
